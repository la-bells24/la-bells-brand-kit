# La Bells brand kit

The logo, colours, type, icons, app icons, print, social templates, share cards and email header for **[La Bells](https://shoplabells.com/)**, an online baby and kids' shop delivering across Pakistan.

- Shop: **[shoplabells.com](https://shoplabells.com/)**
- View the kit: **[la-bells24.github.io/la-bells-brand-kit](https://la-bells24.github.io/la-bells-brand-kit/)**

Everything is in one self-contained file, [`index.html`](index.html). Each piece downloads as an SVG (print) or PNG (phones, Canva, Word).
